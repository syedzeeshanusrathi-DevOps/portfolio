# Professional Portfolio Website

This is a clean, modern portfolio website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — main landing page
- `styles.css` — responsive styling and layout
- `script.js` — mobile navigation behavior

## Customize
1. Replace `Your Name` with your real name.
2. Update the bio text and project descriptions.
3. Replace `YOUR-LINKEDIN` with your LinkedIn username in the links. The current site already uses `https://www.linkedin.com/in/syedzeeshan-tech`.
4. Replace the Medium link if you want to use a different publishing profile. The current site uses `https://medium.com/@syedzeeshanusrathi`.
5. Replace the GitHub link if needed. The current site uses `https://github.com/syedzeeshanusrathi-DevOps`.
6. The page now includes a dedicated GitHub section under the main navigation.
7. Update the email address in the contact section.

## Launch
Open `index.html` in a browser to view the site. You can also deploy it to GitHub Pages, Netlify, or Vercel.
